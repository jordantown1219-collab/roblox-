`data/detroit_walk_route.json` defines a102.350349m route (365.536960studs), five waypoints, starting on existing source path55897361 and ending along the12m Hart Plaza paving trial on path106403203. It crosses continuous source plaza rather than inventing a new surveyed path. The Amber spawn is over150m from the trial even in a straight line; this bounded route therefore starts on the nearby source path and preserves the spawn.

The route generator requires the entire.65m-radius body corridor (4.642857stud width) to remain inside source Hart Plaza/land and outside all source building polygons and estimated ground-level buffered roads. It also excludes projected collidable standing-height geometry from geometry.json and detail_preview.json, using all eight transformed bounding-box corners for conservative obstructions. Surfaces with tops at/below.85stud are treated as walkable; geometry wholly above8stud is ignored. This validates conservative source clearance, not a live Roblox navigation mesh or dynamic character/vehicle safety.

The viewing waypoint names refer to the civic/plaza setting. Exact building reference IDs are recorded; no guaranteed visibility or visit to a building entrance is claimed. Original land origin42.329/-83.040 and scale1/.28 are retained. Surface Y=.35stud is an estimated review datum, not a measured ground ray for each waypoint. Lead should raycast downward and place the Humanoid above the actual returned surface before walking. Do not use waypoint Y directly as a root-part height.
