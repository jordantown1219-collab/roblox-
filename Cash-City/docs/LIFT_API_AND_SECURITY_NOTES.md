# Lift contract and references
ResidentialAccess.build(root,plan): preserves original parts and installs exact exterior replacements before opening passages. ResidentialLift.build(root,config) returns requestRide(player,stopIndex), state and Destroy; requests are server-validated, serialized, proximity/LOS/alive/cooldown checked. No client-supplied positions, speed or passenger lists. Gates close before movement and only open at a dock. Production construction access stays disabled until acceptance.
Official sources reviewed: https://create.roblox.com/docs/scripting/security/client-server-boundary ; https://create.roblox.com/docs/reference/engine/classes/ProximityPrompt ; https://create.roblox.com/docs/reference/engine/classes/WeldConstraint ; https://create.roblox.com/docs/reference/engine/classes/Model ; https://create.roblox.com/docs/reference/engine/classes/BasePart .
